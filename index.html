Problems with Mean-Variance Optimization

Run Markowitz optimization on J.P. Morgan's published forward-looking capital market assumptions and watch it fail. Expected returns are noisy and correlation matrices are unstable, so the optimizer behaves as an estimation-error maximizer: it concentrates the portfolio in whichever asset classes happen to carry the most favorable forecast error. The last tab builds the standard fixes.

How diversified is this frontier?

Averages taken over the 101 frontier portfolios. Classes in the allocation counts weights above 0.5%. Weight dispersion is √Σ(wi − 1/N)², Idzorek's frontier-variability idea: it is zero for an equally weighted portfolio and 1 for a single-asset portfolio, so lower means more evenly spread. Effective number of classes is 1/Σwi², the number of equally weighted positions that would give the same concentration.

Portfolio at a chosen risk level

The frontier portfolio closest to the target volatility, with each class's weight, its share of total portfolio variance, and its marginal contribution to risk. At the maximum-Sharpe portfolio the ratio of excess return to marginal risk contribution is equal across every class that is held — that is the condition the optimizer is enforcing.

Shock the forecasts

Chopra and Ziemba (1993) found that at a moderate risk tolerance, mean-variance optimization is about 11 times more sensitive to estimation error in expected returns than in variances, and about 2 times more sensitive to variances than to covariances. Shift any forecast below and watch the weights move. One standard error of an expected return is σ/√T, so the slider is denominated in standard errors for an assumed sample length.

Which input is the optimizer most sensitive to?

Each row perturbs one kind of input by one standard error's worth of noise, holding the others at the J.P. Morgan values, and reports how far the target-volatility portfolio moves. Turnover is ½Σ|Δwi|, the fraction of the portfolio that would have to be traded. Averaged over many independent noise draws.

Expected returns are perturbed by σi/√T, volatilities by their own standard error σi/√(2T), and correlations by the standard error of a sample correlation, (1−ρ²)/√T, with the shocked correlation matrix repaired to the nearest valid one. If returns move the portfolio far more than the other two, the lecture's point stands: the optimizer is mostly reacting to the input we estimate worst.

Frontiers you might have drawn instead

Each faint line is the frontier you would have computed if your expected returns had been drawn once from N(μJPM, σ²/T) — that is, if your forecast had been wrong by a perfectly ordinary amount. The solid line is the J.P. Morgan frontier. The spread is the honest uncertainty in the frontier's location; the allocation chart underneath shows that the uncertainty in the frontier's composition is far worse.

Reference portfolio for reverse optimization

The Black-Litterman anchor is the set of expected returns implied by a portfolio you are willing to call efficient: Π = δΣwref. The J.P. Morgan file has no market capitalizations, so pick a reference portfolio below — a policy benchmark works just as well, and Idzorek notes this is how the model is used in practice.

Resampling

Implied equilibrium returns vs. the J.P. Morgan forecasts

Reverse optimization spreads the estimation error in the volatilities and correlations across the return forecasts, producing returns that are a clean linear function of beta risk. Classes sitting far from the 45-degree line are where the J.P. Morgan view disagrees most with equilibrium — and in a traditional optimizer, those are exactly the classes that would dominate the allocation.

Security market line

Idzorek's Figure 5. By construction the implied excess returns are exactly proportional to beta against the reference portfolio, so every class has the same ratio of implied excess return to beta. Changing the risk premium rotates this line and changes the frontier's shape, but it does not change the resulting allocations.

Add views

A view states an expected total return for one class. Confidence 100% replaces the equilibrium return outright; lower confidence shrinks the posterior back toward equilibrium, which is what keeps the allocations diversified.
